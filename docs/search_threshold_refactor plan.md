# Рефакторинг управления порогом поиска (distance)

Цель: упростить управление допуском результатов и убрать путаницу «MIN/MAX», оставив одну главную точку управления — максимальный допустимый порог `SEARCH_MAX_DISTANCE`. Минимальный порог полностью исключить. Добавить адаптивный механизм повышения порога, если начальный запрос не дал результата, и привязать верхнюю границу к известному максимуму метрики конкретного провайдера эмбеддингов.

## Проблема текущего состояния
- Две переменные окружения для границ (`SEARCH_MAX_DISTANCE_MIN`, `SEARCH_MAX_DISTANCE_MAX`) усложняют понимание и приводят к конфликтам.
- Пользовательские настройки содержат `threshold`, что провоцирует «минимаксинг» и лишнюю сложность для пользователя.
- Адаптация порога реализована однократно (расширение до лучшего кандидата) и завязана на env‑границы, а не на реальные пределы метрики провайдеров.
- Отсутствует единый источник истины о максимальном диапазоне метрики (например, Xenova cos distance ∈ [0..2]).

## Целевое состояние
- Одна переменная: `SEARCH_MAX_DISTANCE` — главный и единственный порог допуска для distance.
- Минимальный порог удалён полностью (отсутствует в коде и .env).
- Порог пользователя удалён из `settings_store` и UI: пользователь не управляет порогом, просто получает результат.
- Адаптивный поиск: если первый проход пустой, порог временно повышается по шагам до верхней границы метрики провайдера.
- В `src/services/embeddings/index.js` появляется карта провайдеров с максимальной дистанцией (`distanceMax`) и описанием метрики.
- Количество адаптивных итераций и шаг вынесены в .env (например, `SEARCH_ADAPTIVE_ITERS`, `SEARCH_ADAPTIVE_STEP`).

## Ключевые решения
- Используем только `env.SEARCH_MAX_DISTANCE` как входной порог.
- Верхняя граница адаптации берётся из карты провайдеров: `providerMeta[provider].distanceMax`.
- Если карта не даёт верхнюю границу — используем безопасный дефолт (например, `2`).
- Итеративная адаптация: `threshold += step` до максимума метрики или до достижения результата; число попыток ограничено `SEARCH_ADAPTIVE_ITERS`.
